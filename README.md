# Thammasat Data Scrollytelling

เว็บเล่าเรื่องด้วยข้อมูล (data scrollytelling) เกี่ยวกับมหาวิทยาลัยธรรมศาสตร์ เลื่อนหน้าจอเพื่อดูแต่ละซีน

- เปิด `index.html` ในเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลด GSAP, D3 และฟอนต์)
- ไลบรารี: GSAP + ScrollTrigger, D3.js, TopoJSON
- ชุดสีออกแบบให้คนตาบอดสีแยกได้ (Okabe–Ito / ColorBrewer)
